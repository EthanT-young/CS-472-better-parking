# Better Parking Web App

Frontend application for the **Better Parking** CS 472 project.

The web application provides the user-facing interface for viewing parking garage availability, parking spot information, and other data provided by the Better Parking backend and Supabase database.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
